# 战斗文字

客户端实时采样生物生命值变化，在实体颈部附近显示像素风伤害或治疗数字，为玩家提供即时的战斗视觉反馈。

**模块状态**：客户端 · 已实现 · 依赖：无

## 行为

- **伤害**：生命值下降时显示，数字位于实体颈部附近、左侧区域。
- **治疗**：生命值上升时显示，数字位于实体颈部附近、右侧区域。
- 数字面向摄像机，出现后快速放大、回落到正常比例、向上漂浮，并在生命周期末段淡出。
- 只显示正整数（四舍五入，最小为 `1`）。
- 首次观察实体时只建立基线，不显示数字。
- 世界切换、连接和断开时，旧采样与活动文字被清理。

### 动画生命周期

| tick | 行为 |
|---|---:|
| 0 | 缩放 `0.65` |
| 3 | 峰值缩放 `1.15` |
| 6 | 回到 `1.0` |
| 16 | 开始淡出 |
| 24 | 生命周期结束 |

文字在生命周期内单调向上移动，最大垂直偏移 `0.55` 世界单位。

### 容量与剔除

- 活动文字最多 `256` 个，每 tick 最多新建 `64` 个；超出上限时淘汰最旧文字。
- 超过摄像机 `48` 格或不在视锥内的文字不渲染。
- 对当前玩家不可见的实体不生成新文字。

## 设置

通过总控菜单（`/soulcore-client`）切换两个独立开关：

| 开关 | 默认 | 关闭后的行为 |
|---|---|---:|
| 伤害显示 | 开启 | 不再生成伤害文字，并在下一客户端世界 tick 清除已有伤害文字 |
| 生命恢复 | 开启 | 不再生成治疗文字，并在下一客户端世界 tick 清除已有治疗文字 |

禁用期间会继续更新生命值采样基线；重新开启时不会补发禁用期间的旧变化。

配置持久化在 `config/soulcore-client/combat-text.properties`：

```properties
damageEnabled=true
healingEnabled=true
```

## 已知限制

- 客户端采样只能得到相邻 tick 的净变化，无法区分同一 tick 内的多次伤害或治疗。
- 纯吸收值下降依赖实体的近期受伤状态（`hurtTime`）才显示为伤害；吸收增加或自然失效不显示数字。
- 数字被四舍五入为整数，小于 `0.5` 的有效变化仍显示 `1`。
- 隐身实体不产生新文字。
- 当前只支持数字字符 `0-9`，不显示小数、负号、伤害来源或实体名称。

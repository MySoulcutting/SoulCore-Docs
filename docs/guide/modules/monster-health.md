# 怪物血条

在敌对生物头顶显示始终朝向摄像机的本地化名称、橙红生命条和当前生命数值，让玩家无需打开其他界面即可判断怪物剩余生命。

**模块状态**：客户端渲染 + Paper 名称规则 · 已实现 · 依赖：客户端 Mod；服务端规则受客户端效果通道控制

## 行为

- 只显示**敌对生物**：同时满足 `LivingEntity` 与 `Enemy`、仍存活且最大生命值为正。
- 不显示玩家、友好动物、中立生物或非生命实体。
- SoulCore Paper 成功协商名称规则时，只显示命中服务端 `mob_health.yml` 的敌对生物。
- 血条锚定在实体碰撞箱顶部上方，名称在血条上方居中。
- 名称保留实体名称自带的颜色与样式（无颜色时使用 `#A80000` 暗红色），使用原版文字阴影。
- 同时显示四舍五入后的整数生命数值和按当前/最大生命比例填充的橙红像素条。
- 显示血条的怪物会**隐藏原版名牌**；血条关闭、实体不再符合条件、断线或切换世界后恢复原版名牌。

### 渲染规则

- 血条为 billboard，使用正常深度测试，**不穿墙**。
- 超出视锥或距离摄像机 32 格以上时不渲染。
- 每 tick 最多保留距离玩家最近的 `128` 个有效怪物。
- 位置使用 tick 前后坐标和当前 partial tick 插值，移动时不会固定在旧坐标。

## 服务端名称规则

Paper 配置文件：

```text
plugins/SoulCore/modules/mob_health.yml
```

`name` 是客户端看到的完整纯文本名称列表：

```yaml
name:
  - "僵尸"
  - "深渊领主"
```

| 写法 | 行为 |
|---|---|
| `name: ["*"]` | 显示全部敌对生物；默认配置使用此值 |
| 普通名称 | 区分大小写，执行完整名称精确匹配；颜色和样式不参与匹配 |
| `name: []` | 不显示任何怪物血条 |

- 最多加载 64 个名称；超出或无效的条目会跳过并写入服务端日志。
- 下发规则要求 `config.yml` 中根 `enabled`、`modules.client-effects` 与 `protocol.effects-channel-enabled` 均为 `true`。
- 修改后执行 `/soulcore reload`。在线兼容客户端会收到完整规则，并清空旧的名称判定缓存与可见快照。
- 上述开关关闭、旧服务端、无 SoulCore Paper 插件或未协商该能力时，客户端会保持兼容行为：显示全部符合条件的敌对生物。

## 客户端设置

总控菜单（`/soulcore-client`）中的「怪物血量」开关，默认开启。关闭后下一客户端世界 tick 清空快照并停止渲染。

本地开关拥有最终否决权：即使服务端规则命中，关闭后也不会显示。配置持久化在：

```text
.minecraft/config/soulcore/monster-health.properties
```

```properties
enabled=true
```

## 已知限制

- 客户端只显示已经同步到本地的生命值，无法显示服务端刻意隐藏或未同步的数据。
- `Enemy` 是原版敌对生物契约；未实现该接口的第三方怪物不会自动显示。
- 本版不显示等级。
- 大量怪物场景只保留最近 128 个，防止无界渲染开销。
- 服务端名称规则不是实体类型规则；同名敌对生物会得到相同判定。

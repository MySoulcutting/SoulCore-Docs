# 拾取提示 HUD

当当前玩家从世界中**实际拾取**物品时，在屏幕右下区域显示包含物品图标、本地化名称和拾取数量的通知，并支持自由调整显示位置。

**模块状态**：客户端 · 已实现 · 依赖：无

## 行为

- 通知格式：`x数量 名称 [物品图标]`，数量为黄色，名称保留物品名称自带颜色（未指定时为白色）。
- 通知从区域底部向上滑入，同屏最多 **5 条**，最新条目位于底部。
- 每条显示约 3 秒（60 tick），最后 10 tick 线性淡出。
- 不提示：经验球、容器转移、合成产物、命令给予、创造模式直接放入背包。
- 不合并同类拾取，每个拾取数据包形成一条通知。
- 切换世界或断线时清空通知，不跨世界残留。

### 队列与动画

- 新通知从列表裁剪区域底部向上滑入，滚动动画持续 `6` tick。
- 同屏最多 5 条；加入第六条时立即淘汰最上方最旧条目，其余条目向上滚动。
- 年龄小于 50 tick 完全不透明，50 至 60 tick 线性淡出。

## 设置拾取 HUD 位置

两种方式打开位置设置界面：

```text
/soulcore-client pickuphud
```

或在总控菜单中点击「设置拾取 HUD 位置」。

- 按住预览任意位置可整体拖动，拖动范围限制在屏幕内。
- 提供「重置位置」与「完成」按钮。
- 自定义位置以**右边距**和**下边距**持久化，重启客户端后恢复。
- 屏幕尺寸变化或配置越界时，完整预览会被限制在 `8` 像素安全边距内。

配置持久化在 `config/soulcore/pickup-hud.properties`：

```properties
rightMargin=36
bottomMargin=48
```

## 已知限制

- 若拾取数据包到达时对应物品实体已不存在，则无法取得物品栈并忽略该通知；原版拾取不受影响。
- 使用 GUI 缩放后的像素，具体物理屏幕距离随 GUI Scale 变化。
- 图标由原版渲染器提交，不显示经验球拾取。

# CustomQuest 任务追踪 HUD

SoulCore `1.4.0` 接收 CustomQuest 的服务端权威任务快照，在客户端右上区域显示多任务追踪面板，并提供滚动、收起、布局调整和一键导航。

**模块状态**：客户端 · 可选集成 CustomQuest · 不依赖 SoulCore Paper 插件

## 面板内容

- 默认宽度 `172`、列表高度 `92` GUI 像素，位置为右边距 `12`、上边距 `16`。
- 最多显示 5 个任务，每个任务最多显示 2 行目标。
- 任务标题和目标 bullet 优先使用任务 YAML `name` 首个可见字符前的 `&0`–`&f` 颜色；没有颜色时按任务类型回退。
- 目标进度在右侧显示为封顶后的 `当前/总数`。
- 相邻任务由细横线分隔；内容超出列表高度时使用右侧滚动条。
- 配置了导航目标的任务显示「导航」按钮，当前目标显示「导航中」；没有目标的任务不显示按钮。
- 标题栏右侧箭头可收起面板。收起后只保留同宽标题栏与展开按钮，不再绘制或响应任务、导航按钮和滚动条。
- 按 F1 隐藏 GUI 时，任务面板也会隐藏。

## 操作任务面板

正常游戏视角会锁定鼠标。按 `T` 打开原版聊天并解锁鼠标后，可以：

- 点击标题栏箭头收起或展开；
- 拖动右侧滚动条滑块，或点击滚动轨道；
- 把鼠标放在展开状态的任务列表上滚轮浏览；
- 点击「导航」开始导航，再次点击「导航中」请求取消。

只有任务面板实际命中的区域会消费鼠标事件；聊天输入区和其他区域仍由原版聊天界面处理。导航请求只携带稳定任务 ID，服务端会重新校验玩家、任务与目标。

## 调整位置和尺寸

从总控菜单点击「设置任务追踪 HUD 布局」，或直接执行：

```text
/soulcore-client questtracking
```

在布局设置页中：

- 拖动面板主体移动整个 HUD；
- 拖动左下角手柄调整宽度和列表高度，文字大小不变；
- 右侧滚动条仍可拖动、点击轨道或使用滚轮；
- 「重置」恢复默认位置、尺寸与展开状态；
- 完成、关闭或松开拖动后异步保存配置。

允许的尺寸范围：

| 项目 | 默认 | 范围 |
|---|---:|---:|
| 面板宽度 | `172` | `120`–`260` |
| 列表高度 | `92` | `60`–`180` |

完整预览会限制在屏幕 8 像素安全区域内。低 GUI 高度下，总控菜单会自动改用两列按钮布局。

## 配置文件

```text
.minecraft/config/soulcore/quest-tracking-hud.properties
```

```properties
rightMargin=12
topMargin=16
panelWidth=172
listHeight=92
collapsed=false
```

| 字段 | 说明 |
|---|---|
| `rightMargin` | 面板到屏幕右侧的 GUI 像素边距 |
| `topMargin` | 面板到屏幕顶部的 GUI 像素边距 |
| `panelWidth` | 面板宽度 |
| `listHeight` | 展开时任务列表的可见高度 |
| `collapsed` | `true` 仅显示标题栏，`false` 展开列表 |

位置、尺寸与收起状态会持久化；任务快照与滚动位置只属于当前连接，不写入磁盘。

## 协议兼容与清理

新客户端同时支持任务追踪 v1、v2 和 v3，服务端按 v3 → v2 → v1 选择双方支持的最高版本：

- v1：基本任务和进度。
- v2：增加任务颜色与稳定任务 ID。
- v3：增加可导航标记与导航按钮状态。

CustomQuest 每 5 秒发送一次完整快照作为心跳。客户端约 13 秒没有收到合法快照时会自动清空，避免插件热禁用或代理切换后残留。加入、断线或服务端发送 CLEAR 时也会立即清空。

没有安装配套 CustomQuest、服务器未声明通道或尚未发送快照时，面板保持为空；SoulCore 不会自行推断任务进度。

## 常见排查

- 面板为空：确认 CustomQuest 支持任务追踪通道，并检查客户端与服务端版本是否匹配。
- 没有「导航」按钮：该任务需要在 CustomQuest 中配置导航目标，并由服务端发送 v3 快照。
- 鼠标不能滚动或点击：先按 `T` 打开聊天，或进入任务追踪布局设置页。
- 任务突然消失：查看服务端是否停止发送心跳；约 13 秒超时清空是安全保护。
- 与其他 HUD 重叠：使用 `/soulcore-client questtracking` 和 `/soulcore-client pickuphud` 分别调整位置。

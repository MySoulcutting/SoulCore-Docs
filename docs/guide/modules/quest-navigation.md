# CustomQuest 任务导航

SoulCore `1.4.0` 接收 CustomQuest 的服务端权威导航目标，并在客户端世界中绘制信标光柱、目标圆环和任务名/距离标签。

**模块状态**：客户端 · 可选集成 CustomQuest · 不依赖 SoulCore Paper 插件

## 开始导航

在 CustomQuest 的 `/quest` 任务书中点击任务的「导航」，或在[任务追踪 HUD](/guide/modules/quest-tracking)中点击可导航任务的按钮。服务端重新校验任务和目标后，客户端显示当前单一目标。

## 显示效果

| 距离目标 | 显示内容 |
|---:|---|
| 不超过 `256` 米 | 青色信标光柱、不会被地形遮挡的旋转圆环、任务名与距离悬浮标签 |
| 超过 `256` 且不超过 `512` 米 | 青色信标光柱 |
| 超过 `512` 米 | 不显示导航视觉 |

- 光柱复用 Minecraft 原版信标纹理。
- 圆环不进行世界深度测试，因此会作为导航标记透过地形显示。
- 悬浮标签始终面向相机，并随距离平滑放大到明确上限。
- 标签显示三维直线距离的四舍五入整数值。
- 不绘制屏幕底部导航 HUD；任务名与距离只显示在世界目标处。

这些效果完全由客户端渲染。服务端不会为导航创建方块、实体、粒子或 ActionBar，也不会强制加载目标区块。

## 结束与清理

以下情况会停止当前导航并清理标记：

- 再次点击正在导航任务的「导航中」按钮；
- 切换目标、到达、完成或放弃任务；
- CustomQuest 重载；
- 客户端断线、重新加入或切换世界。

玩法判定仍由 CustomQuest 负责；客户端距离显示不参与到达或完成判断。

## 配置

本模块没有客户端配置文件。目标坐标、到达距离与任务关联在 CustomQuest 中配置。

## 常见排查

- 完全没有标记：确认客户端为 SoulCore `1.4.0` 或协议兼容版本，且 CustomQuest 已识别客户端通道。
- 只有光柱：目标可能超过 256 米但仍在 512 米以内，这是正常行为。
- 超过 512 米消失：属于渲染距离上限，不代表服务端导航已取消。
- 标记没有清理：提供客户端 `logs/latest.log`、服务端日志和最小复现步骤，并说明是取消、到达、重载还是换世界后残留。
